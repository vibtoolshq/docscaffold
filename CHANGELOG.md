# Changelog

## v1.0.0 — 2026-11-19

First stable public release of DocScaffold.

- Configuration-driven multi-repository Markdown/MDX documentation portal built on Astro.
- Two-step Git sparse checkout, .vibtools metadata auto-discovery, docs navigation and Pagefind search.
- Static output with SEO/sitemap and AI/LLM-readable endpoints.
- Cloudflare Pages and Docker/Nginx deployment options.
- Public-only default project registry; private product docs, keys, local logs and internal engineering notes are not included.
- Public-release safety guard, locked dependencies, unit tests and GitHub Actions verification.

Release policy: v1.0.0 is the stable GitHub source release. Website deployment and any hosting configuration are managed separately.
